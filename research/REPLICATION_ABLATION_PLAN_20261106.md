# 全量基线、随机种子与消融补验协议

日期：2026-11-06。任务是整理全部实验并补充验证，不修改论文正文、现有图表或写作交接指南。

## 1. 为什么最近五臂不足以成为主比较

Transport25、Blank25、Views25、Detail25、Lowpass25 是同预算候选机制筛查，主要检验空间传输、填充、真实视角缓存、图像细节和低通输入。完整比较还需要：

- YOLO-Master-N、YOLO11-N、YOLO12-N：完整检测系统的实际参照，已有 checkpoint 评估单列。
- FroFA、LOFF-TA 的检测任务思想适配：直接相关的缓存特征增强方法。已有 30 个配置/种子 pilot，须补完整数据评估才能进入全量结果表。
- C1/C2、Random Mix25、Online100：缓存、简单真实查询混合、每次重新提取真实特征的基础策略；保留已有完整三种子结果。
- 校正器、门控、路由及冻结头机制诊断：保存已完成证据与负结果，不将诊断结果当训练 AP。

结果总账见 [RESULTS_LEDGER.md](RESULTS_LEDGER.md)。FroFA/LOFF-TA 是相关方法基线；张老师 ICLR/ACL 的模型编辑论文属于写作与机制对照范例，两者角色不同。

## 2. 固定设置

- 完整 VisDrone，6471 train / 548 development validation；不使用 test-dev。
- 冻结 DINOv3-S/16，640，第 3/7/11 层，FP16 特征缓存；mean_value 融合检测头。
- 100 epochs，batch 8，AdamW lr 0.001、weight_decay 0.0005，cosine 至 0.00001；原生检测损失，梯度裁剪 10。
- 同种子的头初始化、样本顺序、请求翻转与连续缩放计划一致；翻转概率 0.5，缩放 [0.85,1.15]。
- 查询按图像累计取整，包含尾批次：累计数量为 floor(epoch × 6471 × query_pct / 100)。不同预算的 query mask 不强求相同，但图像顺序及请求变换必须相同。
- 25% 组间完整计划相同。Mix25 的非查询图像使用真实 C2 原始尺度，因此实际有效增强与 Transport/Blank 策略不同，作为整体策略对照解释。
- FroFA-C2 使用原始尺度 C2 与逐通道亮度增强 δ=0.1；LOFF-TA-C2 使用对应几何传输与相对通道标准差噪声 0.05。超参数取已存在 pilot 的代表配置，不查看完整验证集后另选最好值。二者均是检测思想适配，非原论文完整复现。
- Detail0/Blank0 保持对应方法的连续增强请求，只将训练真实骨干查询预算改为 0；缓存构建查询仍需计入首次成本。Detail0 仍读取 RGB，不能称零图像输入或零计算。
- 验证频率统一为每 10 轮和最后一轮；主指标是固定第 100 轮、548 图的 VisDrone 官方参考实现 AP。诊断 DetMetrics 与官方参考 AP 分列。
- RGB 和 Lowpass 分支均增加 4672 参数，保持相同结构、初始化和检测监督。低通处理保持先 area 640→40，再 bilinear 40→640。

## 3. 原数据与缓存迁移

服务器重装后，原项目、数据和环境在数据盘上的位置变化，旧 JSON 和符号链接仍包含此前绝对路径。

新任务建立独立 assets/source 与 assets/cache，只生成迁移后的元数据和指向既有特征文件的链接；原始 manifest、标签、缓存、运行记录和 checkpoint 不改写。逐文件验证内容身份，保留原始与迁移后的配置版本、映射及构建成本来源。禁止为此重复生成约 89 GiB 的新增视角缓存。

启动前校验软件版本、离线权重和真实特征/缓存一致性。当前已核对 torch 2.13.0、CUDA 13、numpy 2.2.6、scipy 1.15.3、transformers 5.15.1 与已有 Detail25 运行记录一致。驱动/资源状态另行记录。

GPU0 实际 CUDA 前反向测试通过。GPU1 的实际初始化返回无可用 CUDA GPU，当前仅排 GPU0 串行队列。每次运行记录 telemetry；若发生共享资源竞争，则该段计时保留并标明条件，不能宣称受控加速。

## 6. 指标与产物

每个完整运行保存：配置、初始化状态标识、逐轮训练与验证记录、请求/有效增强及查询计划、配额计数、最终模型与预测身份、官方参考 AP/AP50/AP75/AR500、原始图像读取、缓存构建/复用、训练/验证/墙钟、显存、环境及资源 telemetry。

- AP 使用 0–100；主要采用固定最终轮，不替换成历史 best。
- 训练种子报告原始点、均值和样本标准差。N=3 的不确定性如实说明，不用图像 bootstrap 冒充独立训练重复。
- 时间分别给首次使用与缓存复用口径，不重复加总嵌套计时。查询图像数、调用数、RGB 支路开销分别记录。
- 全量任务与机制诊断结果分别汇总。补充材料保留早期小规模探索和失败结果。
- 存储使用流式特征读取；重复实验复用现有缓存。只保留必要最后检查点与最终预测，不积累每轮完整权重副本。
