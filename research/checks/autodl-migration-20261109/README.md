# VOC download-package metadata audit

Date: 2026-11-09, Asia/Shanghai. The paired JSON records a local read-only audit of the three exact Ultralytics assets `v0.0.0` ZIP URLs used by the new AutoDL preparation script. This audit did not change the running preparation script or start training.

The audit used `E:\Anaconda\python.exe` with standard-library `urllib.request`, `struct`, `zipfile`, `zlib` and `xml.etree.ElementTree`. HEAD determined each file length; bounded positive-offset HTTP Range requests read the ZIP tail, central directory, official split member and contiguous XML region. Every accepted range returned HTTP 206 and exactly the requested byte count. The single-range limit was 12 MiB. XML and split payloads were decompressed in memory and checked against the central-directory CRC and uncompressed size. No ZIP or dataset payload was written locally.

All three packages use `VOCdevkit/VOC{year}`. Comparing complete non-directory member paths found no shared file names between any two packages, so the observed releases have no file-content merge conflict. Shared parent directories are normal.

The official selected splits contain 5011 VOC2007 trainval, 4952 VOC2007 test and 11540 VOC2012 trainval images. All 21503 selected XML annotations were parsed. Their 62199 objects, including 10109 difficult objects, contain no nonfinite, noninteger, reversed, zero-origin or out-of-image box under the script's strict predicate. Their XML image filenames also match the selected IDs. The VOC2012 package has 17125 XML files in total; the additional XMLs are not part of its official detection trainval set and were not included in this coordinate audit.

This supports retaining strict conversion `[xmin-1, ymin-1, xmax, ymax]` to zero-based half-open training boxes while preserving authoritative VOC XML and difficult flags. [Detectron2's maintained VOC loader](https://raw.githubusercontent.com/facebookresearch/detectron2/main/detectron2/data/datasets/pascal_voc.py) documents the same inclusive-coordinate interpretation. Archive names and official split sizes are also supported by the [maintainer's VOC configuration](https://raw.githubusercontent.com/ultralytics/ultralytics/main/ultralytics/cfg/datasets/VOC.yaml); the [VOC development-kit documentation](https://www.robots.ox.ac.uk/~vgg/projects/pascal/VOC/voc2012/htmldoc/index.html) defines the original layout and annotation format.

This is **not** a full JPEG download/decode validation, complete ZIP CRC check, dataset completion seal, or detection result. No complete archive SHA256 was obtained or invented. The running full preparation must still validate all downloaded ZIP members, decode every selected JPEG, compare JPEG/XML dimensions, hash all real assets and write `complete.json` only after those checks pass. Release URL and observed byte length alone do not establish immutable content identity.
