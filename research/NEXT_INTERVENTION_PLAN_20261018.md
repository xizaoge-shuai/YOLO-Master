# 下一步：区分填充修复与目标定位恢复

日期：2026-10-18。状态：方案，尚未启动；不是已取得的实验结果。

## 决策依据

两种冻结头下，真实分配都不能充分恢复定位输出梯度。
新结果进一步显示：Mix25 头的 Transport 在 0.85 倍缩小视角出现分类失配和梯度幅值放大；Rec 能明显纠正分类，定位改善较有限。
输入特征在两头实验中完全相同。因此需要区分空间误差位置、头的敏感性和任务信号，而不是继续以全局 MSE 排名候选。
已完成的保护恒等视角、前景加权、TaskAware 训练没有建立超过 Mix25 的收益；不重复包装这些方案。

## 第一优先级：空间分区与填充干预

固定此前 128 张训练开发图和两个 seed-0 冻结头，0.85/1/1.15 × 翻转/不翻转；每个视角的真实特征一次提取后供两个头和所有干预共享。校正器固定。记录所有教师调用。
开发集用于确定实现和取舍；已有 548 张验证图用于一次锁定协议后的复核，不能称为未使用测试集。

先用变换后的有效图像支持图和原始 letterbox 元数据定义互斥区域：新增填充、原有 letterbox 填充、有效图像前景、有效图像背景。
特征边界的双线性混合带单独计数；不可把它默认为纯前景或纯填充。前景采用所有可见 GT 框片段，并记录框过滤与遮挡规则。
各层分别记录区域大小、平方误差总量及其全局占比、区域归一化误差。不同区域的归一化 MSE 不可直接相加。

最小比较：

| 干预 | 实际操作 | 回答的问题 |
|---|---|---|
| Transport | 保持原传输 | 原始参照 |
| Rec | 保持既有校正器 | 已学修复的收益在哪里 |
| Exact | 使用真实特征 | 每个头自己的参照 |
| Padding oracle | 只把新增填充区域换为真实特征，其余保留 Transport | 填充恢复是否足以解释分类恢复 |
| Content oracle | 只恢复有效内容区域，保留填充 | 目标/背景内容是否贡献主要定位恢复 |
| Cheap padding | 原传输加 `(1-warp(ones))*blank_feature`，blank_feature 来自一次灰色图像前向 | 简单非学习填充是否已解决问题 |

Cheap padding 的灰图是图像预处理前 RGB=114/255、同尺寸、同模型/层/精度；按空间位置保存多层特征，保持 scale=1 路径不变。它不是上下文真实填充的替代保证，只是必须测的廉价对照。一次构建成本和额外存储计入。
完整 oracle 恢复属于机制诊断，不作为低成本训练方法；ViT 上下文和检测头感受野使区域效应不能相加为唯一因果分解。

主要指标：固定 exact 分配和公共归一化下，分类/定位输出梯度余弦与相对 L2、范数比；记录原生自分配的损失和匹配覆盖作为辅助。
补测冻结 eval 状态检测头的可训练参数梯度（仅求导、不更新权重），分类与定位分别统计；共享层和分支层分开列出，避免大层支配拼接范数。输出梯度不是参数梯度的替代品。参数梯度诊断也不等于训练期随机批次的长期 AP。

## 第二优先级：控制干预强度，验证定位相关性

第一步的区域全恢复同时改变位置数、能量与内容，因此若存在局部恢复收益，接着做配对强度控制：

- 在有效前景和有效背景中，选相同 token 数 k；k 不超过当前图所有被比较区域的可用数量，使用固定种子抽样，禁止按结果挑位置。
- 每层真实残差分别做范数匹配，以各比较组最小可用残差范数为共同上限，仅缩小、不放大；测固定强度 0.25/0.5/1。零残差或空区域显式记为不可比较，并保留全样本计数。
- 比较真实前景残差、真实背景残差，以及同前景位置/同层范数的随机方向残差。随机方向固定种子并与图像配对，避免将位置差异与方向差异混淆。
- 主终点为定位参数梯度相对误差与方向一致性；输出梯度、小目标对应预测的框误差作为辅助。所有干预共用 exact 分配，再报告原生自分配敏感性。

可检验判断：若等强度前景真实残差在两个头上均优于背景/随机方向，才支持训练“定位相关的选择性修复”候选；若仅填充恢复有效，应先补强 Transport 基线。若参数梯度不支持输出梯度解释，则放弃把输出梯度作为方法目标。
上述是决策规则，不是预期结果或显著性承诺；只有两个已训练头时不作训练种子总体推断。

## 第三优先级：全量、同预算的一个候选

依据上述干预确定一个候选，并先固定模块、损失、超参数与预算；不同时堆叠多种新组件。
正式训练用完整 VisDrone 6471 train / 548 val、相同初始化和增强/查询 schedule，优先 25% 档、三个配对种子；证实有收益再补 10% 档。

必要对照：C2、Random Mix25、Transport25、补强填充的 Transport25、原 Rec25、候选，以及 100% 在线参照。
如果候选利用真实分配/额外蒸馏，加入同查询预算下的简单分配/蒸馏控制，所有额外教师计算计数。
离散缩放真实缓存仍是待补强基线，应在最终主比较前按完整训练集构建并实际计入存储和读取；不能以在线重算代替缓存对照。

主终点：预先固定 epoch 的最终官方协议 AP；附 AP50、明确面积定义的小目标指标、逐种子配对差值。
沿用已核验的参考评估流程并核实 ignore/max_det 等规则；历史训练日志中的 custom DetMetrics 数值不能直接当成官方 VisDrone AP。
成本同时记录实际教师查询数、缓存构建、训练、验证、总墙钟、峰值显存、存储。共享 GPU 的波动计时不用于严格速度声明；另安排受控计时。

如果三个种子的收益方向不稳定或额外成本抵消收益，返回机制判断或停止该候选，不扩大跨域任务来掩盖结果。
有可重复收益后，再开展第二完整数据集、第二骨干和同总时间预算；“目标域重训”与“源域校正器冻结迁移”分别命名、分别报告。

当前可写的研究问题是：缓存增强需要保留哪些与任务相关的响应，以及有限真实前向应补偿哪类失配。
是否形成新方法贡献，需要训练结果和新的近邻方法核验，不能由 D1 的时间新近性推出。
